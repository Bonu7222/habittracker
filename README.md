# simple habittracker

this is a basic no frills habit tracker. i built it to keep my daily goals in chek but also to practice writing clean vanilla code without realying on heavy libraries or frameworks.

## what it does

-- add new habits to the list
-- mark habits as "done" or undo it
-- delete habits you dont want 
-- everything saves automatically to localstorage so it stays there if you refresh

## how to run it

just open index.html in any browser or visit my github @bonu7222
